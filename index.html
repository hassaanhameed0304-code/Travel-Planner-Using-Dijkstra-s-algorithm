    THE LOGIC BEHIND THE ROUTE

    Shortest path.
    Clear reasoning.

    The planner models Karachi as a weighted graph and uses a modified Dijkstra algorithm to choose the best route.

    01
    ⌘

    Build the graph

    Landmarks become vertices. Sample road distances become weighted edges in an adjacency list.

    02
    ⇄

    Compare routes

    A priority queue processes the closest unvisited location first, updating better distances.

    A parent array traces the chosen route back from the destination to the starting point.
